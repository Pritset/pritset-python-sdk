# Changelog

All notable changes to the Pritset Python SDK are documented here.

## 0.1.5 - 2026-08-31

- Add synchronous and asynchronous clients for template management and document generation.
- Add stream-first binary responses, typed models, multipart uploads, and normalized API errors.
- Pin Pritset SDK contract 1.0.0.
- Add offline unit, contract, package, and clean-consumer verification.
- Add a guarded, opt-in lifecycle test for a dedicated production test user.
